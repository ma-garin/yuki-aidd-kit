# /plan — 方針の確定（実装モード解除・探索許可）

引数: $ARGUMENTS（プロジェクト概要 or 調査対象）

## 実行内容

調査と方針確定のフェーズ。実装モードを解除して探索（Read/Grep/Glob）を許可し、方針を固める。

1. **実装モードを解除**
   - `.claude/mode` が存在すれば削除する（`rm -f .claude/mode`）。これで `block-explore.sh` hook が探索を再び許可する
2. **調査 → 方針提示**
   - OPERATING-MODE.md「実装ループ」に従い、対象ファイルを grep/glob で絞ってから読む
   - 判断軸＋選択肢比較の形式で方針を提示し、合意を取る
3. **PLAN.md を生成/更新**
   - 確定した方針・対象ファイル・検証手順を記載する（次フェーズの実装がこれだけを見て進められる粒度）
   - **見積（分）・ステップごとの推奨モデル（Haiku / Sonnet / Opus）・トークン節約の手**を必ず含める（`rules/model-routing.md`。保守者は毎回これを求める）
   - **着手前の 5 つの質問**に各 1〜2 行で答える: ①設計判断が要る箇所と選択肢 3 つ・推奨理由 ②顕在化しうるリスクと影響 ③レビュアーが最初に突く点 ④見込み往復数と超えたときの短縮案 ⑤成功しない可能性が最も高い箇所と最初の Step で潰せるか。**答えられない質問が残る状態で `/implement` に入らない**
   - 別モデル（Sonnet / Haiku / Codex）に実装を渡すなら、PLAN.md でなく `02_共通/ひな形/work-order.md` の型で作業指示書を書く（守ること表・Step ごとの完了条件・止まる条件）
4. 方針が固まったら `/implement` で実装モードに入る

**`.claude/mode` は存在すれば必ず削除すること**（探索許可状態へ戻す）。
