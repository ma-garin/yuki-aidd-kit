# /ralph — 完了の合言葉が出るまで同じ依頼を回し直す（opt-in の完了ループ）

引数: $ARGUMENTS（回し直す依頼文。任意で先頭に `--max N`（既定 5・上限 20）と `--done 合言葉`（既定 `RALPH_DONE`））

## 実行内容

1. 引数から依頼文・max・合言葉を取り出す。依頼文が空なら何もせず「依頼文を付けて呼ぶ」と返す
2. `.claude/ralph.json` を Write で作る（既にあれば上書きせず、`/cancel-ralph` で消すかを保守者に聞く）
   ```json
   { "prompt": "<依頼文>", "iteration": 0, "max": 5, "done_phrase": "RALPH_DONE" }
   ```
3. 依頼文の作業を始める。応答を終えるたびに Stop フック `ralph-stop.py` が合言葉の有無を見て、無ければ同じ依頼を渡し直す
4. **本当に終わったとき（検証まで通したとき）だけ**応答に合言葉を書く。終わっていないのに書いて抜けない
   （合言葉を書くと検証の有無にかかわらずループが止まる。完了の主張は done-gate スキルの手順で裏付ける）
5. max 回に達したら止まる。そのときは何が終わっていないかを 1 行で報告する

## 注意

- 状態ファイルが壊れていると何も消さずにループしない（警告だけ出る）。中身を直すか `/cancel-ralph`
- 状態ファイルは作ったセッションに結び付く。別のセッションの Stop では動かない
- 自己ウェイク・定期実行ではない（Stop の差し戻しを max 回まで繰り返すだけ。時間で起きる仕組みは作らない）
- **Codex では使えない**（Stop フックが無い）。Codex では依頼を 1 回ずつ人が出し直す
