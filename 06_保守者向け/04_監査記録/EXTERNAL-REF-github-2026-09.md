## 方法

1. 列挙: awesome リスト・MCP レジストリ 45 件の clone（11,416 件）＋10 領域の検索（npm・PyPI・crates・GitHub topic・README 群）。重複除去で 21,069 件
2. 説明文判定: 全件を 250〜500 件ずつ判定（共通の判定規則 kit-context）。取りこぼし見直し 11 バッチ＋キーワードで絞った落選 846 行で 79 件を引き上げ
3. 精読: 有益候補・要確認・引き上げ分 2,298 件（全件を判定）の README を raw で取得し 40 件ずつ判定（58 バッチ）
4. 否定側の検証: 精読で有益となった 863 件を Sonnet が崩す立場で検証し 39 件を降格。**検証は弱い**（降格率 4.5%、根拠は adoption と evidence の文面のみ）ため、採用前に人の判断が要る

## 欠けているもの・注意

- 精読 2 バッチ（80 件）は一度遅延で打ち切ったが、翌 0 時台に Opus で判定し直して反映済み
- README が取得できなかった 168 件は説明文だけで精読判定（CSV の根拠列が空）
- Sonnet の精読は有益判定が多い（Opus 約 4 割に対し 6〜8 割）。確認レベル列で区別できる
- Web 検索はセッション上限 200 回に達し、記事サイト（Zenn・Qiita・note 等）は遮断（Q-17 で通信許可しないと決定）。日本語記事にだけ載るリポは欠けている
- ★・最終更新は GitHub API がセッション範囲外のため空。手元で enrich_github_meta.py を実行すれば埋まる
