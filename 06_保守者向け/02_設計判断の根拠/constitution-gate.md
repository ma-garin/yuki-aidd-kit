## 決定: 指示でなく制御
| 制御 | 動作 |
|---|---|
| 停止 file | 違反 1 回で `.claude/constitution-stop` を書く。存在する間は PreToolUse が全ツール deny。猶予・回数の閾値は設けない |
| 解除は保守者のみ | file の rm/mv/上書き・Write/Edit を本 hook が deny。解除の環境変数は作らない。保守者が自分の端末で消す |
| 事後分析の必須化 | `.claude/constitution-stop.last` の時刻より `06_保守者向け/学んだこと.md` が古ければ deny。振り返りを書くまで再開できない |
| 見積ゲート | コーディング指示の後、このターンに `見積：N分` 行（新書式 `見積：N分（HH:MM）` を含む）が無ければ deny（読み取り専用ツールは 3 回まで許可） |
| 報告ゲート | 最後の見積行／中間行／完了行から 180 秒超（`AIDD_REPORT_INTERVAL_SEC`）で deny。時刻は hook の壁時計 |
| 離席ゲート（Stop） | 委譲先の走行中・計測区間が未了なら block |

| 監査 | 違反は `hook-decisions.log` と `.claude/constitution-violations.jsonl` に残す。`report` で状態表示。`evidence.py` に件数を載せる（次版） |

## 改訂 2026-11-10: Bash の改ざん判定を読み書きで判別する
- 旧判定は「コマンド文字列に保護 file の名前がある」かつ「どこかに `>` か `rm`/`cp`/`ln`/`python3` 等の語がある」で違反（＝停止）にしていた。`ls -ln 名前`・`git commit -m "…名前…rm…"`・`grep -c cp 名前` のように、読み取りの引数に語が出ただけで停止した
- 新判定（許可リスト方式）: 保護名を含むコマンドは、全体が「既知の読み取り専用コマンド（`cat`/`head`/`grep`/`rg`/`ls`/`test`/`find`/`git log` 等）を `;` `&&` `||` `|` で並べただけ」と構文的に確定できたときだけ許可する。それ以外は判別不能として違反（A-14 安全側既定）
- 判別不能に倒すもの: 引用符の外のリダイレクト全種（`<` を含む。区切り記号と隣接していても 1 文字ずつ検出）・`$`（変数・`$(...)`・`$'..'`）・バッククォート・バックスラッシュ・`=`・ブレース/グロブ（`{}*?[]`）・`()`・`!`・`~`・背景実行の `&`。許可リスト外のコマンド（eval・sudo・xargs・シェル・インタプリタ・sed・awk・書き込み系）。書き込み・任意実行の選択肢（`rg --pre`、`git -c`/`--output`/`-O`/`--ext-diff`、`find -exec/-ok/-delete/-fprint*/-fls`）
- 読み取りを許可する根拠: 停止 file の中身は「時刻・違反種別・ツール名」だけで迂回手段にならず、旧版のテスト 26 も読み取りを許可していた
- 回帰の担保: テストに差分検査を組み込み、origin/main 版の判定関数と同じ入力群を流して「旧 deny → 新 allow」の逆転が 0 件であることを確かめる。意図して解消した誤検知（上の 3 例）は別の入力群で「旧 deny・新 allow」を確かめる
- 限界（旧版でも素通り。範囲外としてロードマップ M25 に残す）: 保護名の文字列を含まないコマンド（`.claude` ごとの削除・glob・変数での組み立て・インタプリタ内で名前を作る等）は判定しない。名前の照合は大小区別の部分一致で、ブレース展開・zsh の glob 選択・`$'..'` の 16 進表記・大文字表記で名前を割ると通る
