# 環境チートシート（speed-harness H-2 の本体。プロジェクトごとに `.claude/` へ写して埋める）

プロジェクトごとに埋める。作業中に探索した項目は終了時にここへ追記する。
```bash
<起動コマンド>                                                                 # 検証用: 認証オフ・ブラウザ自動オープンなし
curl -s --retry 15 --retry-delay 1 --retry-connrefused -o /dev/null -w "%{http_code}" http://127.0.0.1:<PORT>/   # 待機ループを組まない
kill $(lsof -ti:<PORT>) 2>/dev/null                                            # ポートで止める。pkill・killall・pgrep|kill は他セッションと自分を巻き込むので hook が止める
```
- 編集の反映条件（再起動が要るか / ホットリロードか）: <記入>　／　認証・外部通信を止める手段: <記入>
- 既知の不具合・触ってはいけないファイル: <記入>　／　スクショは scratchpad の絶対パスを最初から `filename` に指定

| 場面 | 標準 |
|---|---|
| 一時ファイルの片付け | `mv <対象> <scratchpad>/`（削除でなく退避） |
| コミット対象／PR の作成とマージ | パスを明示して `git add <path...>`（`git add -A` 禁止。`block-destructive.py` が deny する）／別々のコマンドとして順に実行（連結すると Base branch was modified で失敗） |
| 複数ファイルの編集 | Read 全件1メッセージ → Edit 全件1メッセージの2往復に固定 |
| 複数セッションが共有する作業ツリーでの git | ブランチ切替をしない。HEAD でコミット → `git worktree add <scratchpad>/wt -b <name>` の別ツリーで rebase・push・PR・マージ |
| 複数パスを git に渡す | 変数に入れず明示して並べる（zsh は `$P` を単語分割しないので 1 つのパスとして渡り失敗する） |

安全フックに止められたら、安全装置が正しく働いた結果として受け入れ、標準コマンドに切り替える。`reset --hard` / `clean -fd` / `stash drop` / `checkout --` / `push --force` / `rm -rf` も `block-destructive.py` が deny し、理由に代替手段を載せる。
