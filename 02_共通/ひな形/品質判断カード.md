# 品質判断カード

変更 1 件につき 1 枚。**埋められない項目があれば、その項目が次の作業。** 書き方の根拠: `02_共通/rules/quality-decision.md`。

| 項目 | 記入 | 記入指針 |
|---|---|---|
| 変更 | | 何を、どの版で変えるか |
| 守るもの | | 誰が何をできればよく、何ができてはいけないか |
| 失敗 | | 許容できない失敗の仕方。誰に何が起きるか |
| 要求 | | 確かめる要求の ID と内容 |
| 確認範囲 | | どの要求をどの版で確かめるか。未確認の範囲も書く |
| 証跡 | | 何を数え、どこに残すか |
| 停止条件 | | 何が 1 件でも出たら先へ進めないか |
| 担当 | | いつ・誰が見て、誰が止める／進めるを判断するか |
| 再開条件 | | 停止後、どの証跡がそろえば再開するか（停止条件と対） |

## 記入例（図書館の貸出）

| 項目 | 記入 |
|---|---|
| 変更 | 貸出画面に利用者の貸出履歴表示を追加（v1.4） |
| 守るもの | 利用者が自分の履歴を見られる。他の利用者の履歴は見えてはいけない |
| 失敗 | 他の利用者の履歴が見える（漏えい、取り消せない）／上限超過や延滞中の貸出が通る |
| 要求 | R1 貸出上限 5 冊／R2 延滞中は貸出不可／R6 他利用者の履歴非公開 |
| 確認範囲 | R1・R2・R6 を v1.4 で確認。未確認: 図書館間の相互貸出 |
| 証跡 | 要求ごとの確認セットの実行結果と版番号を CI の記録に残す |
| 停止条件 | 他の利用者の履歴が見える状態が 1 件でも確認されたら先へ進めない |
| 担当 | リリース前に QA 担当が確認し、停止・再開は開発リーダーが判断する |
| 再開条件 | 修正版で R6 の確認セットを通し直した証跡があり、提供する版が確認した版と一致 |
