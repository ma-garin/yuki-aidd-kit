## 0. この指示書の読み方

- 手順は上から順に行う。順序を変えない

### 守ること（違反したら差し戻し）

| 禁止 | 理由 |
|---|---|
| `git add -A` / `git add .` | 未追跡ファイルを巻き込む。パスを列挙する |
| 完了条件の証跡（テスト末尾 1 行・スクリーンショット）を出さずに「完了」と書く | 完了の唯一の条件は「<この作業の完了条件を 1 行で>」 |
| 対象外ファイルを変える: <触ってはいけないパス> | この作業は <範囲> のみ |
| ゲート・テスト・しきい値を通すために弱める | A-12。3 回連続で赤なら止まって報告する |
| 文章を生成して埋める（根拠のない説明・推測の数値） | 数値・判定・根拠だけを並べる。無いものは「未提供」「未計測」と書く |
| `sleep` によるポーリング・バックグラウンド実行 | 常駐サーバの起動のみ例外 |
