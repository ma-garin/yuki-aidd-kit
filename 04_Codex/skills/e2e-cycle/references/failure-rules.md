# ステップ4: 分類の当てはめ・flaky判定・locator破損の修復

`e2e-cycle` ステップ4（ODC分析・段階的修整・再テスト）から参照する。分類の語は
`02_共通/ひな形/test/iso29119-incident-report.md`・`iso29119-test-completion-report.md`・
`skills/test-strategy` と一致させる: 製品欠陥 / テスト陳腐化（locator破損／仕様変更） / 環境・データ依存 / flaky（タイミング／順序・共有状態／通信／乱数・時刻）。

## 6マス（分類の前に必ず埋める）

| | 常時 | 間欠 |
|---|---|---|
| **製品** | 製品欠陥 | flaky の疑い（製品側のタイミング依存） |
| **テスト** | テスト陳腐化（locator破損／仕様変更） | flaky の疑い（テスト側の順序・共有状態依存） |
| **環境** | 環境・データ依存 | flaky の疑い（通信・乱数・時刻依存） |

再現性が「間欠」のマスに入ったケースだけ、下の flaky判定の反復手順に進む。「常時」のマスはそのまま確定でよい。

## Playwright のエラー文 → 分類の対応表

| エラー文の特徴 | 第一候補 | 次点 | 見分け方 |
|---|---|---|---|
| `locator.click: Timeout ... waiting for element` | locator破損 | 製品欠陥（要素が本当に出ない） | トレースでその要素が画面に存在するか確認する。存在して locator が外れているだけなら破損、存在しないなら製品欠陥 |
| `expect(locator).toHaveText(expected)` 不一致 | 仕様変更 | 製品欠陥 | 期待値が最新の設計・文言と一致するか確認する。設計側が変わっていれば仕様変更（テストを直す）、変わっていなければ製品欠陥 |
| `net::ERR_CONNECTION_REFUSED` / `net::ERR_*` | 環境・データ依存 | — | 対象サーバ・モックが起動しているか、ポート・環境変数が合っているかを確認する |
| 単独実行では毎回PASSし、並列実行時だけ FAIL | flaky（順序・共有状態） | — | 下の flaky判定手順で確定する |
| 実行のたびに結果が変わる（単独でも） | flaky（タイミング／乱数・時刻） | — | 下の flaky判定手順で確定する |

## flaky判定の反復手順（「対象テストのみ1回だけ」規則の唯一の例外）

`GATES_REQUESTED=1` の下で、FAIL した**そのケースだけ**を対象に行う（テスト全体は回さない）。

```
npx playwright test -g "対象テスト名" --repeat-each=5 --workers=1 --retries=0 --trace=on
```

- **全敗**（5/5 FAIL）: 決定的な失敗。flaky ではない。製品欠陥かテスト陳腐化として通常の分類に戻る
- **結果が揺れる**（PASS と FAIL が混ざる）: flaky。原因側（タイミング／順序・共有状態／通信／乱数・時刻）を上の6マスから選ぶ
- **単独では全勝するが、元の並列実行では落ちる**: 競合（順序・共有状態）。テスト間のデータ共有・実行順依存を疑う（`tests/fixtures/` 等の後始末漏れが典型）

反復結果は `iso29119-incident-report.md` §5「n 回中 m 回 PASS（単独/並列）」の欄にそのまま転記する。

## locator破損の修復手順

1. `trace: 'retain-on-failure'`（ステップ2の設定）で取れたトレースを開き、失敗時点の ARIA スナップショットを見る
2. 対象要素を次の優先順位で locator に置き換える候補を探す: `getByRole` → `getByLabel` → `getByText` → `getByTestId` → CSS セレクタ（この順で上から採用できるものを使う。CSS は最後の手段）
3. 候補が決まったら `count() == 1` かつ可視（`toBeVisible()`）であることを確認する。2件以上ヒットする候補は採用しない
4. 差分は locator の行だけにする。アサーション・期待値・テストの意図は変えない
5. 自動修復ライブラリ（self-healing locator 等)は導入しない。上記の手順を人（またはエージェント）が判断して置き換える
