# 作業の計測（見積 → 中間 → 完了の 3 行）

体感の見積は当たらない（実測 0.16 倍＝6 倍の過大見積が出た）。**見積は直近の予実から校正し、実測は時計で測り、終わりに並べる。** これを毎回同じ書式で出すと、保守者は本文を読まずに進み具合が分かり、AI は自分の見積の癖を数で直せる。

## 3 つの固定書式（文字・区切りを変えない）

| いつ | 書式 |
|---|---|
| 開始（最初のツール呼び出しより前。応答の 1 行目は `見積: N分（HH:MM 完了予定）`、続けて次の行） | `【見積：N分 \| 開始:HH:MM \| 終了:HH:MM \| タスク数：n】` |
| 中間（前回の計測行から 1 分以上経ってツールを呼ぶ合間。待ち受けの応答にも出す） | `【進捗:前倒し/順調/遅れ \| 経過時間：M分 \| 終了:HH:MM \| タスク数:k/n】` |
| 終了（成果物を渡す応答。**最後の行**に `見積: N分 / 実測: M分` を置く） | `【見積:N分 \| 実測:M分 \| 開始:HH:MM \| 終了:HH:MM \| 作業時間記録:成功/失敗】` |

- 時刻は `TZ=Asia/Tokyo date +%H:%M`（または `metering.py now`）で取る。推測で書かない。「JST」の文字は付けない
- 「終了」は開始時刻に見積を足した**予定**。中間行の「終了」は遅れていれば引き直す
- タスク数 n は着手前に作業を独立単位へ分解した数。k は終わった数
- 見積は「素の見積 × 校正係数」。係数は `metering.py factor`（実測/見積の中央値。3 件未満なら 1.0 扱い）
- 2 分以内でも・至急でも例外にしない（急ぐ場面ほど飛ばすため）

## 守ること・やらないこと

- **実測は時計の値。**数えていなければ「未計測」と書く。体感で埋めない
- **待ち受けの中間応答に見積行（`見積: N分（…完了予定）`）を再掲しない。**区間が未了なのに「経過 1 分で見積 6 分＝過大」と誤判定される（2026-10-15 の実測）。中間は中間行だけ
- 1 ターンに `見積: N分 / 実測: M分` は 1 行だけ。開始行【見積：】は作業全体、末尾行はその区間の予実
- **乖離したら原因を 1 行**: 実測が見積の 1.5 倍を超えた、または 3 分の 1 未満（過大見積）なら、原因を 1 行書き、実測記録（`metering.py note "<原因>"`。既定は kit の `06_保守者向け/02_設計判断の根拠/speed-harness.md`）に追記してから報告する。ルールを新設せず、見積の作り方（分解不足・並列本数・委譲の固定費・検証パスの抜け）のどこで外したかを書く
- 見積と経過が離れても**途中で数字を下げない**。再見積は「超過前に、理由を添えて」1 回

## 報告の型（完了時。10 行以内）

1. 変更したファイル　2. テストの末尾 1 行（`PASS=n / FAIL=m`。回していなければ「未実行」）　3. 未達・要判断（あるときだけ）　4. 最後の行に `見積: N分 / 実測: M分`

## ハーネス別の動かし方

| | Claude Code | Codex |
|---|---|---|
| 見積の注入・現在時刻・係数 | `prompt-priority.py` が毎発言で注入 | 発言を受けたら `python3 <skill>/scripts/metering.py factor` と `now` を叩いて自分で出す |
| 実測 | `tool-timer.py`（hook が自動計測。`report` で貼る） | `metering.py begin "<作業名>" <見積分> [n]` → `mid <k>` → `end [成功\|失敗]`（壁時計で測る） |
| 末尾行の強制 | `reply-language.py` が Stop で差し戻す | 規約のみ。`end` が末尾行まで印字するので、その出力をそのまま貼る |
| 予実の履歴 | `~/.claude/tool-time.json` の `history` | **同じファイル**を読み書き（無ければ `~/.agents/metering.json`）。係数は両ハーネスで共有して育つ |

Codex の最小手順:

```bash
M=~/.agents/skills/work-metering/scripts/metering.py   # kit から配布された場所
python3 $M factor                       # 例: 0.50 14 → 素の見積に 0.50 を掛ける
python3 $M begin "System08 要件定義" 13 4   # 開始行を印字（応答の 2 行目に貼る）
python3 $M mid 2                        # 1 分以上経った合間に印字して貼る
python3 $M end 成功                      # 終了行＋`見積: N分 / 実測: M分` を印字。履歴に記録。乖離なら note を促す
python3 $M note "待ち受けの中間応答に見積行を再掲した"   # 乖離したときだけ
```
