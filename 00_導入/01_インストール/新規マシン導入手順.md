# 新規マシン導入手順 — 手元と同じ挙動にする

新しい PC・クラウドセッションで、手元と同じ hook・規則・個人設定で Claude Code を動かすための手順。
各手順の「確認」コマンドが期待どおりでなければ、次へ進まず 7 の対処表を見る。

## 1. 前提を揃える
- python3（3.9 以上）・git・Claude Code
- 確認: `python3 --version && git --version && claude --version`

## 2. plugin を導入する（hooks・skills・commands が入る）
1. Claude Code で `/plugin marketplace add ma-garin/yuki-aidd-kit`
2. 続けて `/plugin install yuki-aidd-kit@yuki-aidd-kit`
- 確認: `python3 00_導入/03_点検/doctor.py` の表で `D10 hook 配線` に plugin の `hooks.json` が OK で出る

## 3. グローバル設定が要る場合（statusLine・env・規則を `~/.claude/` に置く）
- plugin では statusLine・env を配れないため、必要なら `./00_導入/01_インストール/install.sh` を実行する
- 確認: `./00_導入/01_インストール/verify.sh; echo rc=$?` が rc=0、`python3 00_導入/03_点検/doctor.py --home` の `D9 規則ハッシュ` が OK

## 4. 手元 clone の `.claude/settings.json` を揃える（保守者）
- AI は `.claude/settings*.json` を当てない。保守者が `06_保守者向け/01_内部仕様/settings-patch-portable.md` の手順で差分を当てる
- 確認: `python3 00_導入/01_インストール/gen-wiring.py --check --strict; echo rc=$?` が rc=0

## 5. 個人設定を戻す
- `05_プロジェクト管理/personal-config/README.md` の「戻し手順」に従う（userPreferences・メモリのエクスポート）
- 確認: `git ls-files 05_プロジェクト管理/personal-config/` が `README.md` と `.gitignore` の 2 件だけ（本文はコミットされていない）

## 6. doctor で全緑を確かめる
- `python3 00_導入/03_点検/doctor.py; echo rc=$?`
- 確認: 最終行が `全緑`、rc=0

## 7. 赤のときの対処表
| 赤の項目 | 原因 | 対処 |
|---|---|---|
| D3・D4 hook の配線・構文 | キットの checkout が壊れている | `git status` で改変を確かめ、`git checkout -- 03_ClaudeCode/hooks` |
| D9 規則ハッシュ（キット内） | 規則を変えたが台帳を更新していない | 保守者が `python3 00_導入/03_点検/doctor.py --write-manifest` |
| D9 規則ハッシュ（`--home`） | `~/.claude/rules/aidd-kit/` が古い | `./00_導入/01_インストール/install.sh` を再実行 |
| D10 (a) 未登録・(d) 先頭でない | settings の配線が真実源と違う | plugin を再導入するか、`gen-wiring.py --target global` の出力に合わせる（`~/.claude/settings.json` は保守者が当てる） |
| D10 (b) 実体なし・(c) 権限／構文 | hook ファイルが無い・実行権限なし | `install.sh` を再実行、または `chmod +x` |
| D10 WARN 未導入 | settings にキットの hook が無い | 2 または 3 を行う |
| D11 A-2 発火 | constitution-gate.py が動かない | `bash 06_保守者向け/03_回帰テスト/test-constitution-gate.sh` で原因を見る |
| D12 TZ・CLAUDE_CODE_GOAL_CHECKIN_MINUTES | 環境変数が無い・値が違う | 3 の `install.sh`（settings の env）を行うか、シェルで `export TZ=Asia/Tokyo` |
| D12 GH_TOKEN / gh auth status | GitHub の認証が無い | `gh auth login`、またはセッションの GH_TOKEN を設定 |
