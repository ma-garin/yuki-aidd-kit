# UI/UX レビュー観点（74件）

実際に起きた不具合から起こした観点。「不合格の例」はすべて実際に発生したこと。

項目の構成は外部の体系に合わせている。

| 項目 | 準拠先 |
|---|---|
| 対象 | VSTeP のテスト観点／実務テンプレートの「機能要素」 |
| 条件 | ISTQB の Preconditions・Inputs／TestRail の Preconditions |
| 確認方法 | ISTQB の Test Actions／TestRail の Steps |
| 期待結果 | ISTQB の Expected Results／TestRail の Expected Result |
| 優先度 | TestRail の Priority |
| 品質特性・副特性 | ISO/IEC 25010:2023 |

優先度: 高=先へ進めない／誤りに気づけない、中=判断を誤る、低=手間が増える
