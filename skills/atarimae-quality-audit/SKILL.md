# 当たり前品質 徹底監査

「当たり前品質(Kano の must-be)」= **満たされても満足は生まれないが、欠けると強い不満・怒りを生む**要素。
その中身は作り手でなく**使い手の暗黙の期待**で決まり、要求仕様に書かれない。だから作り手側の机上列挙では
必ず抜ける。このスキルは、その抜けを**発見者として先回りで潰す**ための手順。

## 最優先の作法（このスキルの本体）
1. **追認者でなく発見者になる。** ユーザーの指摘1点は"症状"。「その通り」で終わらせず、
   その裏の**欠陥クラスを自分で全列挙**してから着手する。同意の多さは、問題発見を相手に丸投げしている兆候。
2. **机上で満足しない。** コード読解/テスト緑だけでOKにしない。**実機の描画を必ず目視**する
   （描画・挙動レベルの崩れはコードやテストからは構造的に取りこぼす）。
3. **虚偽の断定をしない。** 「確実に通る」等は禁物。verified / 未verified を正直に区別する。
4. **系統的な欠陥は共通基盤で一括修正。** テンプレ個別に貼らず、共通JS/CSS/partial/フォームハンドラで直す。

## 手順

### 1. 静的スキャンで候補を出す（発見の起点）
対象プロジェクトのルートで:
```bash
bash <kit>/skills/atarimae-quality-audit/scan.sh
```
当たり前欠陥の**候補**をクラス別に列挙（インライン塗りバグ / 破壊的操作の確認欠如 / 内部表現の露出 /
軸なしチャート / ページネーション欠如 / 空状態欠如 / オートフィル対策 / 桁区切り / 二重送信対策 等）。
**ヒットは候補であって結論ではない**（偽陽性が混じる）。必ず 2. で実機確認する。
スキャンに出ない型（レスポンシブ崩れ、時間軸の張り付き、フォーカス、色コントラスト等）は 3. の目視で拾う。

### 2. 実機で描画を目視する
Web は Playwright/`chromium-cli` で駆動（このキットの `test-automation` / `browser-qa` と接続）。
- **CSS/JS を変えたら必ずキャッシュを破棄してからスクショ**（ブラウザは古いCSSを掴む）:
  ```js
  document.querySelectorAll('link[rel=stylesheet]').forEach(l=>{ l.href=l.href.split('?')[0]+'?v='+Date.now(); });
  ```
- **狭幅(モバイル)でも確認**（表の横溢れ・折返し崩れは狭幅でしか出ない）。
- スクショは**必ず目視**。空/エラー/崩れが見えたら未完了。

### 3. 系統的に直し、再検証する
共通基盤で直す → 実機スクショで再確認 → ビルド/型/テスト（`test-automation`）→ `done-gate`。
文言変更でテスト期待値が古くなったら更新する。

## 当たり前欠陥カタログ（実プロジェクトで検出・修正した型と、正しい直し場所）
| 型 | 症状 | 直し場所 |
|---|---|---|
| インライン塗りバグ | `<span>` を進捗塗りに使い width/height 指定 → inline は寸法無視で不可視 | CSS に `display:block`（`<div>`なら不要） |
| チャートの識別不能 | どのバーがどの項目か不明 / 軸目盛なし | 標準の2ペイン(左に固定ラベル列)＋Y軸ラベル(HTML)＋グリッド線 |
| 時間軸の張り付き | 末尾タスクに密着・横スクロール不可 | 範囲に前後余白＋既定を横スクロール可能に＋「今日へ」 |
| 二重送信・無反応 | 長時間ボタン押下後も無反応で多重送信可 | 共通JSで `aria-busy`＋「処理中…」（`disabled`は値欠落するので不可） |
| 破壊的操作の確認欠如 | 削除等に確認なし | フォームに `data-confirm`＋共通ハンドラで処理 |
| 内部表現の露出 | `None`/`[]`/dict/英語ステータス/`manage.py`等が画面に | 表示前に人間可読な日本語へ整形・正規化 |
| ページネーション/検索欠如 | 件数増で全件表示・探せない | 共通 pagination partial ＋ view で `Paginator`／検索 |
| オートフィル暴発 | 認証系フォームに既存資格情報が自動挿入 | `autocomplete="off"/"new-password"` |
| 桁区切りなし | 大きな数が読みにくい | `intcomma` / `toLocaleString` |
| 時刻非依存の挨拶 等 | 22時でも「おはよう」 | サーバ側で文脈判定して渡す |
| 空/エラー/読込状態の欠落 | 空リストが無言・失敗が生エラー | 各状態に人間向けメッセージ＋次の導線 |

## Gotchas
- **CSS変更が反映されない** = ブラウザキャッシュ。上のキャッシュ破棄JSを毎回。サーバ配信は
  `curl -s <url>/static/xxx.css | grep <新ルール>` で確認できる。
- **共有ブラウザの汚染**: Playwright の永続プロファイルに過去/並行セッションの残タブが居座り、
  アクティブタブが勝手に遷移することがある。作業タブを固定、想定外タブは無視。`ps ax | grep playwright` で確認。
- **`--reuse-db` のフレーク**: シードマイグレーション系テストが稀に落ちる。`--create-db` で再実行すると通る。
- **エージェントの禁止事項**: パスワード入力・アカウント作成・権限/共有変更・恒久的削除は行わない。
  検証用データは識別可能な接頭辞（例「検証:」）にし、後で掃除する。

## 関連（このキット内）
`qa-review-standards`(ISO/ISTQB の基準) → 何を欠陥とみなすか。本スキル → どう発見し系統的に直すか。
`test-automation` → 動作をテストで固定。`done-gate` → 完了判定。`accessibility`(ECC) → alt/label/WCAG。
